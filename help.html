Help Center

Folder Management

How do I add my first video folder?

Open Settings and enter the absolute directory path that PHP can read, such as /home/user/Videos or D:\Media\Videos, then choose Authorize.

How do I add another folder?

Repeat authorization in Settings. MediaPlay keeps all valid authorized directories. Use “Remove” beside a directory to remove only that directory.

Can I add folders from both C: and D: drives?

Yes. If PHP is running with permission to read each drive, you may authorize directories on each drive separately.

Why is the website asking for folder permissions?

Browsers do not allow websites to freely discover arbitrary folders. The native folder picker or the server-readable path field ensures access is explicit and limited.

Why are some videos missing?

Check that the folder is authorized, readable by PHP, and contains a supported extension: MP4, MKV, AVI, MOV, WMV, WEBM, M4V, MPG, MPEG, or TS.

Subtitles

How do I add subtitles?

Place an SRT file beside the video and use the same filename: MyMovie.mp4 and MyMovie.srt. Open the video and use the Subtitles selector.

How do I create my own SRT file?

Use Notepad or subtitle software, save with a UTF-8 .srt extension, and include numbered entries with HH:MM:SS,mmm --> HH:MM:SS,mmm timestamps. 

1\n00:00:01,000 --> 00:00:04,000\nWelcome to my video!
Can the browser generate subtitles automatically?

No. MediaPlay only loads existing SRT or VTT files. Automatic speech recognition would require separately added software or an internet service and is not currently implemented.

My subtitles are not showing.

Confirm a matching filename, an actual .srt extension, valid UTF-8 content, and that the folder remains authorized.

Can I use multiple subtitle languages?

Yes, organize files as MyMovie.en.srt, MyMovie.fil.srt, and MyMovie.ja.srt. Matching base names are offered in the player’s subtitle selector.

Library and Playback

How do thumbnails work?

The library generates thumbnails in the background, saves only each captured image in IndexedDB, and reuses saved thumbnails. Generation is limited to a small queue; unsupported or unreadable videos can be retried from their library card. Videos are not uploaded. Use “Refresh thumbnail” in the player to replace a saved image.

Why is a video not playable?

Try MP4 or WebM first. Some codecs, especially those inside AVI or MKV containers, require FFmpeg or a browser with matching codec support.

How do I use the Mini Player?

Start a video or use browser controls. A floating Mini Player preserves the local playback state while you navigate. It can be minimized or closed.

How do I change font size?

Open Settings, use the Font size controls, and refresh or reopen the site. The preference is saved locally.

How do I enable Incognito Mode?

Open the hamburger menu and select Incognito: OFF to change it to ON. It disables application-level history and playback persistence for your session.

Logging and Privacy

Where are logs stored?

MediaPlay does not create a separate application log file. PHP’s development server prints connection requests and errors only to the terminal.

Does Incognito hide terminal logs?

No. It cannot control PHP, operating-system, browser, or network records. It only prevents MediaPlay from saving application activity in browser storage.

Are video filenames recorded?

The PHP development server may print requested URL paths in terminal output. MediaPlay does not create persistent application logs or transmit filenames elsewhere.

Finals CEEL Mediaplay

Title of the project

MediaPlay

Summary of the project

MediaPlay is a private, local media library for organizing and playing video and music files. It lets users authorize folders, browse their media, manage playlists and favorites, view watch history, and play content without a login or cloud database.

Languages and tools used

Languages: HTML, CSS, JavaScript, and PHP.
Other tools: Local Storage and IndexedDB for browser data, FFmpeg for optional media processing, and the PHP development server.
